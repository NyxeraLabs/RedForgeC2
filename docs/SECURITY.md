# Security & Lab Safety (Simulation Only)

RedForgeC2 is intended for **local lab simulation and education**.

Rules:
- Run only on isolated VMs, sandbox networks, or Docker labs.
- Default-bind services to `127.0.0.1` / `localhost`.
- Do not add modules for exploitation, persistence, evasion, or exfiltration.
- Treat all “tasks” as **mock actions** recorded to logs for training.

See also: `../SECURITY.md`.
